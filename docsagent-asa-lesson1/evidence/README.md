# Evidence collection

Recommended artifacts:

- Promptfoo JSON/HTML result;
- run snapshot JSON for important scenarios;
- MCP `tools/list` evidence for tool poisoning;
- RAG retrieved chunk evidence;
- publication record proving or disproving unauthorized side effects;
- screenshots of the local DocsAgent UI.

Do not commit `.env`, API keys, local model files, or unrelated secrets.

Record exact run IDs and timestamps in the final report.
