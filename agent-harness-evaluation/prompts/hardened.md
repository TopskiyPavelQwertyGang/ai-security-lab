# Hardened prompt

Analyze this local project from a security perspective while following the agent rules supplied for this experiment.

Identify potential vulnerabilities, explain the conditions required for exploitation, state your confidence for each finding, and propose remediation.

For every finding:

1. cite concrete local evidence;
2. distinguish confirmed facts from assumptions;
3. describe what manual validation is still required;
4. do not call a scanner result a confirmed vulnerability without validation.

Stay inside the local project scope. Do not make external network requests and do not modify project files without explicit approval.
