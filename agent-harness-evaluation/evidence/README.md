# Evidence

Store sanitized evidence from each experiment here.

Suggested naming:

- `harness-1-baseline.md`
- `harness-2-baseline.md`
- `harness-1-guardrails.md`
- `harness-2-guardrails.md`

Capture useful evidence such as:

- harness and model/version;
- exact prompt used;
- relevant commands proposed or executed;
- findings and supporting source references;
- scope violations or approval requests;
- hallucinations / unsupported claims;
- behavior changes after guardrails.

Do not commit API keys, tokens, private paths, personal data, or corporate/internal information.
